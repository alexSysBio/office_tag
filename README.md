# Σελίδα γραφείου — Αλέξανδρος Παπαγιαννάκης

Στατική σελίδα για το QR της πόρτας του γραφείου, σε GitHub Pages.
Δημόσια, χωρίς login, χωρίς κόστος, χωρίς build.

**Ζωντανή στο:** <https://alexsysbio.github.io/office_tag/>

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Η σελίδα-κόμβος. Τρεις κάρτες: φόρμα, ραντεβού, θέματα |
| `projects.html` | Τα ερευνητικά θέματα |
| `VAE_Project.png` | Εικόνα του πρώτου θέματος |
| `quiz.ipynb` | Παλιά άσκηση Python. Δεν συνδέεται πια πουθενά |
| `README.md` | Αυτό το αρχείο |

Το QR της πινακίδας δείχνει στη διεύθυνση παραπάνω, **όχι** σε κάποια από
τις υπηρεσίες. Ό,τι κι αν αλλάξεις εδώ μέσα, η τυπωμένη πινακίδα μένει
σωστή και δεν ξανατυπώνεται ποτέ.

---

## Αλλαγή των συνδέσμων

Στο `index.html`, κοντά στην αρχή του `<script>`:

```js
var FORM_URL     = "https://docs.google.com/forms/d/e/.../viewform";
var CALENDAR_URL = "https://calendar.app.google/2aTnBVwU3kJKqUcC9";
```

Αν μια γραμμή μείνει κενή (`""`), η κάρτα της εμφανίζεται γκρίζα με
σήμανση ΣΥΝΤΟΜΑ και δεν πατιέται. Δεν σπάει τίποτα.

## Αλλαγή των καρτών

Πιο κάτω στο ίδιο αρχείο είναι ο πίνακας `ITEMS` — μία εγγραφή ανά κάρτα,
με τη σειρά που εμφανίζονται:

```js
{ href: "https://...",  // ή "" για ΣΥΝΤΟΜΑ, ή "κάποιο.html" για τοπική σελίδα
  title: "Τίτλος κάρτας",
  desc:  "Μία πρόταση για το τι θα βρει ο φοιτητής." },
```

Πρόσθεσε, σβήσε ή αναδιάταξε ελεύθερα. Ο σύνδεσμος μπορεί να πάει
οπουδήποτε: δεύτερη φόρμα, PDF στο Drive, η σελίδα του μαθήματος στο
e-course, ανακοίνωση.

## Ερευνητικά θέματα

Όλα τα θέματα ζουν στον πίνακα `PROJECTS`, στην αρχή του `<script>` μέσα
στο `projects.html`. Ένα μπλοκ ανά θέμα:

```js
{
  title:   "Ο τίτλος στα ελληνικά",
  titleEn: "The title in English",
  tags:    ["Σε εξέλιξη", "Python"],
  img:     "VAE_Project.png",
  imgAlt:  "Τι δείχνει η εικόνα, για όσους δεν τη βλέπουν",
  desc:    "Η περιγραφή στα ελληνικά.",
  descEn:  "The description in English.",
  needs:   "Τα προαπαιτούμενα στα ελληνικά.",
  needsEn: "The prerequisites in English."
}
```

Κάθε πεδίο με `En` μπορεί να μείνει `""` — τότε απλώς δεν εμφανίζεται.
Το ίδιο ισχύει για `img`, `imgAlt`, `needs`.

**Εικόνες.** Ανέβασε το αρχείο στη ρίζα του repo και γράψε σκέτο το όνομά
του στο `img`, π.χ. `"VAE_Project.png"`. Όχι ολόκληρη διεύθυνση του
GitHub: οι σελίδες σερβίρονται από τον ίδιο φάκελο, οπότε το όνομα αρκεί.
Αν το αρχείο λείπει, η εικόνα κρύβεται αθόρυβα αντί να βγει σπασμένο
εικονίδιο.

**Άδεια λίστα.** Αν αφήσεις `var PROJECTS = [];`, η σελίδα δείχνει μήνυμα
ότι δεν υπάρχουν διαθέσιμα θέματα και καλεί τον φοιτητή να στείλει email.
Χρήσιμο όταν είσαι γεμάτος.

## Πού ζουν τα υπόλοιπα

**Η φόρμα σχολιασμού** είναι Google Form. Αλλάζεις ερωτήσεις και περιγραφή
από το forms.google.com· ο σύνδεσμος δεν αλλάζει, οπότε δεν χρειάζεται να
πειράξεις τη σελίδα.

**Τα ραντεβού** είναι appointment schedule στο Google Calendar. Αλλάζεις
ώρες, διάρκεια και περιγραφή από το calendar.google.com· και εδώ ο
σύνδεσμος μένει ο ίδιος όσο δεν σβήνεις και ξαναφτιάχνεις το schedule.

**Το `quiz.ipynb`** είναι μια άσκηση Python σε δεδομένα βακτηριακής
ανάπτυξης, από προηγούμενη εκδοχή της σελίδας. Δεν τη δείχνει πια καμία
κάρτα. Αν τη θέλεις πίσω, πρόσθεσε κάρτα στο `ITEMS` με href:

```
https://colab.research.google.com/github/alexSysBio/office_tag/blob/main/quiz.ipynb
```

Αλλιώς σβήσ' την — οι σωστές απαντήσεις είναι ορατές στον κώδικά της, κάτι
που δεν πειράζει για αυτοαξιολόγηση αλλά δεν κάνει για βαθμολόγηση.

## Δοκιμή πριν δημοσιεύσεις

Μετά από κάθε commit το GitHub Pages θέλει ένα με δύο λεπτά. Μετά:

1. Άνοιξε τη σελίδα από **κινητό**, όχι μόνο από υπολογιστή — εκεί θα τη
   δουν οι φοιτητές.
2. Πάτα και τις τρεις κάρτες.
3. Στη σελίδα κράτησης, διάλεξε ώρα και **σταμάτα πριν το Book** — έτσι
   βλέπεις αν η περιγραφή εμφανίζεται σωστά χωρίς να κλείσεις ραντεβού.
4. Σκάναρε το QR της πινακίδας από την οθόνη.
