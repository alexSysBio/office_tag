# Σελίδα γραφείου — Αλέξανδρος Παπαγιαννάκης

Στατική σελίδα για το QR της πόρτας του γραφείου. Δημόσια, χωρίς login,
χωρίς κόστος. Τρία αρχεία, καμία εγκατάσταση.

| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Η σελίδα-κόμβος: φόρμα σχολιασμού, ραντεβού, quiz |
| `quiz.html` | Το quiz αυτοαξιολόγησης (6 ερωτήσεις) |
| `README.md` | Αυτό το αρχείο |

---

## 1. Ανέβασμα στο GitHub

1. Στο <https://github.com/new> φτιάξε νέο repository.
   Όνομα: `office` (ή ό,τι θέλεις). Διάλεξε **Public** — το GitHub Pages
   δεν δουλεύει σε δωρεάν private repo.
2. Στη σελίδα του repo: **Add file › Upload files**.
3. Σύρε μέσα και τα τρία αρχεία και πάτα **Commit changes**.

## 2. Ενεργοποίηση GitHub Pages

1. **Settings › Pages** (αριστερό μενού).
2. Στο *Source* διάλεξε **Deploy from a branch**.
3. Branch: **main**, φάκελος: **/ (root)**. Πάτα **Save**.
4. Περίμενε 1–2 λεπτά. Η διεύθυνση θα είναι:

   ```
   https://<το-username-σου>.github.io/office/
   ```

   Αυτή η διεύθυνση είναι που θα δείχνει το QR της πινακίδας.

## 3. Σύνδεση της φόρμας και του ημερολογίου

Άνοιξε το `index.html` στο GitHub (κλικ στο αρχείο, μετά στο μολύβι) και
βρες αυτές τις δύο γραμμές κοντά στην αρχή του `<script>`:

```js
var FORM_URL     = "";
var CALENDAR_URL = "";
```

Βάλε τα links μέσα στα εισαγωγικά, π.χ.:

```js
var FORM_URL     = "https://forms.gle/AbCdEf123";
var CALENDAR_URL = "https://calendar.app.google/XyZ456";
```

Όσο μια γραμμή μένει κενή, η αντίστοιχη κάρτα δείχνει «Σύντομα» και δεν
είναι πατήσιμη — δεν σπάει τίποτα.

## 4. Η φόρμα σχολιασμού στο Google Forms

<https://forms.google.com> › **Blank form**. Τίτλος:
**Φόρμα σχολιασμού — Α. Παπαγιαννάκης**.

Περιγραφή:

> Σχόλια, παρατηρήσεις ή παράπονα για το μάθημα, το εργαστήριο και τη
> διδασκαλία. Οι απαντήσεις πηγαίνουν μόνο σε εμένα.

Ερωτήσεις:

1. **Θέμα** — τύπος *Multiple choice*, υποχρεωτική
   - Μάθημα — ύλη και διδασκαλία
   - Εργαστήριο
   - Εξετάσεις και αξιολόγηση
   - Πτυχιακή ή ερευνητική εργασία
   - Άλλο
2. **Το μήνυμά σου** — τύπος *Paragraph*, υποχρεωτική
3. **Μάθημα / έτος σπουδών** — τύπος *Short answer*, προαιρετική
4. **Όνομα** — τύπος *Short answer*, προαιρετική
   Περιγραφή: «Μπορείς να το αφήσεις κενό.»
5. **Email για απάντηση** — τύπος *Short answer*, προαιρετική

Στις ρυθμίσεις (γρανάζι › *Responses*) **μην** ενεργοποιήσεις το
*Collect email addresses* αν θες να μπορούν να γράφουν ανώνυμα.

Μετά: **Send › εικονίδιο συνδέσμου › Shorten URL › Copy**. Αυτό το
`https://forms.gle/…` μπαίνει στο `FORM_URL`.

## 5. Τα ραντεβού στο Google Calendar

Στο <https://calendar.google.com> › **Create › Appointment schedule**.

- Όνομα: «Ώρες γραφείου»
- Διάρκεια ραντεβού: 30 λεπτά
- Γενική διαθεσιμότητα: οι ώρες γραφείου σου
- *Booking form*: ζήτα όνομα και email

Πάτα **Save**, μετά **Share › Copy link**. Αυτό το
`https://calendar.app.google/…` μπαίνει στο `CALENDAR_URL`.

## Αλλαγή των ερωτήσεων του quiz

Στο `quiz.html`, μέσα στο `<script>`, υπάρχει ο πίνακας `QUIZ`. Κάθε
ερώτηση είναι μία γραμμή:

```js
{ s:'Η εκφώνηση;',
  o:['Επιλογή Α','Επιλογή Β','Επιλογή Γ','Επιλογή Δ'], a:2,
  e:'Γιατί είναι σωστή η απάντηση.' }
```

`a` είναι ο δείκτης της σωστής επιλογής και **ξεκινά από το 0** — στο
παράδειγμα πάνω, σωστή είναι η «Επιλογή Γ». Πρόσθεσε ή σβήσε γραμμές
ελεύθερα· τίποτα άλλο δεν χρειάζεται αλλαγή.
